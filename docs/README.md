# 프로젝트 문서

하루 이야기의 프로젝트 정책, 아키텍처 결정, 운영 절차를 찾는 목차입니다. 프로젝트 문서의 적용 순서는 루트 작업 지침에서 확인합니다. [AGENTS.md](../AGENTS.md)

## 문서 배치

| 주제 | 권장 경로 |
| --- | --- |
| 시스템 구조와 기술 제약 | `docs/architecture/` |
| 주요 기술 결정과 근거 | `docs/decisions/` |
| 배포, 운영, 복구 절차 | `docs/operations/` |
| 제품 요구사항과 디자인 기준 | `docs/product/`, `docs/design/` |

거버넌스 문서를 추가할 때 이 목차에 문서 링크와 적용 범위를 기록합니다. 공유 규약은 주제별 문서 한 곳에 두고, 관련 문서는 해당 규약을 링크합니다.
